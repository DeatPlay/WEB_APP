Historie aktualizací a seznam změn v Grammi.

v0.9 Aktuální verze
  • Implementace login stránky.
  • Testování a první předpracování pro SQL propojení.
  • v0.9_1 -> Zprovoznění login systému & SQL databáze.
v0.8 Github
  • Přechod na Github hosting.
v0.7 Changelog
  • Přidána nová záložka Changelog přímo v nastavení aplikace.
  • Verze v hlavičce je nyní klikatelná pro rychlé zobrazení historického přehledu.
  • Vylepšená responzivita nastavení a záložkového menu.
v0.6 Statistiky & Grafy
  • Přepínání grafů mezi Týdenním přehledem a Dnešním průběhem po hodinách.
  • Rozložení dávek do časových oken (Ráno, Odpoledne, Večer, Noc).
v0.5 Ovládání & UI
  • Precision slider pro jemný výběr gramáže s rychlými presety.
  • Apple Liquid Glass spodní navigace s plynulou animací.
  • Dynamický kruhový indikátor doporučeného intervalu.
v0.4 Správa Dat
  • Export a import datových záloh ve formátu JSON.
  • Možnost zpětného zápisu dávky s volitelnou poznámkou.
v0.1 Initial Release
  • První verze systému Grammi pro pohodlné evidování dávek.
